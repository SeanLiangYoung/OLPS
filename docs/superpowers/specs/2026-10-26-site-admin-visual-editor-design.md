# 网站管理后台、可视化编辑与选择发布设计

日期：2026-10-26

状态：交互方向已经确认；本文等待用户审阅。本文描述目标行为，功能完成情况以实施后的检查结果为准。

## 1. 用户目标与已经确认的决定

服务对象为没有技术背景的建站者。用户需要在同一个工作页面获得完成当前任务所需的信息，理解编辑内容、线上内容和发布范围，并直接修改页面。

已经确认：

- 后台以网站为入口，围绕内容管理组织导航。
- 允许只发布选中的页面，编辑器可以发布当前页面，列表可以发布多个页面。
- 页面预览中可以点击选择文字、图片、按钮和内容区域。
- 选中元素后在右侧打开属性抽屉，修改属性并即时显示效果。
- 图片允许上传并替换。
- 广告按钮的 Guide 跳转目标可以在同一个属性抽屉修改。
- 内容区域允许添加、删除、复制、拖动排序，也提供上移和下移。
- 采用围绕现有 HTML 的可视化编辑方案，保留当前生成、预览和静态发布能力。
- 已有页面的 HTML、样式、交互和业务关联需要得到保护。

- `packages/sync/src/workspace.ts` 当前把工作草稿与远端发布版本合并后推送。
- `packages/site-builder/src/plan.ts` 当前根据完整输入生成公开页面、首页索引、robots 和 sitemap。

- 原有功能范围见 `docs/admin.md`、`docs/page-model.md`、`docs/settings-scope.md` 和 `docs/site-collaboration.md`。

实施期间以当前文件为准，保留工作目录中的既有修改。本文新增的目标行为由本文规定；涉及其他能力时继续遵循原有文档。完成后更新相应操作说明。

## 3. 方案选择与实施边界

用户选择围绕现有 HTML 提供可视化编辑。HTML 继续保存页面正文，Guide 继续保存广告路径；编辑器提供元素选择、属性编辑、区域操作及预览。

这一选择能够使用已有页面及模型输出。需要重点处理 HTML 往返保存、CSS 作用范围、系统组件、资源引用以及多人编辑版本。

编辑器库、富文本库、图片处理库及样式解析库由实施者根据实际兼容性验证选择，并记录选择依据。必须使用成熟依赖处理 HTML、CSS 和图片格式。不得自行编写这些格式的 parser。依赖验证使用仓库中的真实页面，检查导入、编辑、导出及运行行为后确定依赖；不使用截图判断元素位置。

本文覆盖后台组织、编辑器、图片管理、Guide 编辑、发布记录、发布预检、发布恢复及相应迁移和验收。当前账号、所有者权限、三类页面、模型生成、询盘、报告和 Google 集成继续提供入口。网站设置继续遵循既有功能范围。

## 4. 网站入口与权限

登录后显示“我的网站”，包含网站名称、访问地址、页面数量、最近更新时间和发布状态。尚未发布的工作也必须可以从这里继续编辑。

以下为设计者提出的默认行为：

- 新建网站同时建立本地网站记录和默认工作草稿；尚未发布时公开地址为空。
- 迁移时，已关联网站的多个工作草稿归入同一网站；未关联网站的现有工作草稿各自建立本地网站记录。保留原有标识和内容。
- 每个账号记住在网站中最近使用且仍有权限访问的工作草稿。仅有一个可用草稿时直接进入；存在多个且没有有效记录时，在进入网站时选择一次。
- 当前编辑版本在网站名称附近以容易理解的名称展示；其他工作草稿从“协作与版本”进入。
- 当前草稿和网站均有权限时才能发布。迁移保持已有所有者列表，不因界面调整授予额外权限。
- 只有草稿权限的用户可以编辑该草稿；网站线上询盘、统计、发布及成员管理继续检查网站权限。

网站入口可以同时列出线上业务记录和所属草稿的历史记录，明确标注来源，并按记录标识去重。迁移不更改历史询盘、报告或集成的原始归属。只有草稿权限的用户继续通过草稿接口读取原本可访问且未关联其他网站的历史记录；已经关联网站的记录继续检查网站权限。网站权限不自动授予全部草稿的读取权限，查询历史草稿记录时必须检查相应草稿权限。统计按明确来源分别计算，避免重复计数。

新建本地网站记录后，不能仅根据 `draft.siteId` 是否存在决定全部业务数据来源。业务接口需要明确区分线上记录与历史草稿记录。历史集成配置作为草稿来源展示，网站尚未配置时可以由有权限的用户明确导入；不得自动替换现有网站授权或混合不同账号的授权信息。

网站与草稿的关联需要支持尚无 `remoteSiteId` 的本地网站。首次发布创建远端网站，并绑定同一个本地网站记录；不得重复创建本地网站或改变询盘和报告的归属。

## 5. 后台导航与信息组织

顶部固定展示当前网站、当前编辑版本、查看网站、发布更改和账号入口。左侧使用固定导航：

- 网站概况：线上状态、待发布更改、最近编辑、最新询盘、可用访问统计及需要处理的问题。
- 页面管理：全部页面、网站页面、内容文章、广告承接页；页面类型在列表中仍然可见。
- 客户询盘：列表、筛选、详情、处理状态和邮件重发。
- 数据与优化：网站统计、Google Ads / GA、页面检查、诊断报告和改写入口。
- 网站设置：语言、地图、WhatsApp、行为采集、广告页屏数上限、成员权限和协作与版本入口。

概况中的数量和问题能够直接进入对应筛选结果。统计注明来源、时间区间和计数含义；没有数据或尚未连接时明确显示当前状态。

生成放在新增页面流程中，改写和翻译放在当前页面操作中。知识库选择、文档管理及目录导入在使用知识的流程中提供入口，并保持已有权限检查。

现有浏览器地址应保留可用的跳转或兼容入口。深层页面必须能够确定所属网站和草稿；切换网站时清除上一个网站的页面选择、统计和表单状态。

## 6. 页面列表与状态

列表提供关键词搜索、页面类型、语言、线上状态、未发布更改筛选，以及排序、分页和多选。展示标题、类型、语言、线上状态、未发布更改、更新时间和常用操作。

线上状态与编辑状态分别计算：

- 线上状态：尚未发布、线上可访问、线上已停止展示。
- 编辑状态：没有未发布更改、有未发布更改、等待首次发布、等待停止展示、等待删除。
- 发布任务状态独立展示：等待执行、检查中、发布中、发布成功、发布失败。

状态以发布快照及当前内容差异为依据，不能仅依赖现有 `PageStatus`。相同内容再次保存不能产生错误的“有未发布更改”提示。比较覆盖正文、SEO、语言关联、地址、Guide 和资源引用，忽略只用于编辑器界面的临时数据。

已发布页面在草稿中删除后，保留待发布删除记录，能够在发布列表中选中。该记录保留页面标识、原标题、原地址和删除时的基础版本。未发布页面删除后直接从列表移除。取消待发布删除时，通过文件编辑和正常保存恢复内容。

新增页面选择用途和语言，并选择自行编辑或 AI 生成。页面地址自动建议且允许修改；冲突和无效地址在操作位置提示。翻译由原页面入口创建或更新，语言关联由系统维护。

## 7. 编辑器界面

中央为页面编辑区域，左侧为内容目录，右侧为选中元素的属性抽屉。顶部提供撤销、恢复、保存状态、设备尺寸、编辑与体验切换以及发布此页面。

点击元素显示选择边框，左侧目录同步选中；父级选择和面包屑允许选择嵌套区域。空白处取消选择。选择边框、工具按钮和临时编辑属性不得进入发布 HTML。

编辑模式阻止普通点击执行跳转、提交表单或触发业务操作。体验模式运行访客交互，使用隔离预览；不得采集线上访客事件或向真实询盘收件流程提交测试消息。需要检查真实询盘流程时使用专门的真实环境验收。

电脑、平板和手机预览调整画布宽度。默认内容修改适用于全部设备。抽屉中影响响应式布局的属性明确显示作用范围；提供分别设置设备样式的入口，并按现有响应式规则生成 CSS。

在较窄管理窗口中，目录和抽屉可分别打开；保留编辑、保存和发布的完整操作。未保存离开时提示保存或放弃本次未保存内容。撤销与恢复覆盖文字、属性、图片替换和区域结构操作；一次连续输入作为合理的一次撤销操作。

## 8. 元素属性与区域操作

文字属性包括内容、标题级别、常用格式、字体、字号、颜色、排列方式和链接。支持直接编辑文字及抽屉修改。

图片属性包括当前图片、上传替换、替代文字、显示宽高、比例、显示区域、裁剪方式及链接。背景图片也提供对应的图片选择入口。涉及 `picture` 或 `srcset` 时同步管理相关来源，防止设备切换后继续显示被替换的旧图。

按钮属性包括文字、目标、颜色、边框、圆角和尺寸。普通按钮可以选择本站页面、指定网址、询盘位置和 WhatsApp；Guide 按钮使用 Guide 目标设置。

区域属性包括背景、内外间距、排列方式和宽度。操作包括添加、复制、删除、拖动排序、上移和下移。区域目录按内容顺序展示，并支持有意义的名称。

新增区域提供标题介绍、图文内容、产品展示、客户案例、常见问题和询盘表单。区域模板使用真实可编辑内容和系统组件；不把模板示例业务数据当作用户已有数据。普通页面允许调整区域顺序；广告页面在当前 screen 内调整区域，screen 的角色和路径由专门操作管理。

复制区域生成新的元素和组件标识，并更新区域内部关联；外部目标保持原意。新增询盘表单接入已有真实询盘配置。删除系统组件或被引用区域时列出具体影响，并要求在确认操作中选择替代目标或处理引用。保持广告页面唯一 CTA screen、有效关键词入口和 Guide 规则。

高级设置允许编辑经过校验的 HTML 属性和 CSS 属性。系统组件标识、事件处理代码和权限相关参数由系统维护，不提供任意执行代码的属性输入。

## 9. HTML、CSS 与编辑内容保存

`body.html` 和 `body.ads.screens[].html` 继续保存正文；`body.ads.guide` 保存 Guide。编辑器使用独立、带版本的元数据保存稳定元素标识、区域名称及必要的映射。选择状态和工具栏状态只保存在浏览器编辑会话中。

必须定义稳定的标识映射及 HTML 保存规则。加载后没有编辑时保持原始内容；编辑时仅修改目标元素及必要的关联内容。不得把整个预览生成结果保存为正文，避免重复加入导航、SEO 或系统运行代码。

成熟依赖解析 HTML、CSS 和资源引用。保存检查正文结构、资源、系统组件和 Guide。样式修改需要确定实际作用对象，防止修改共享 class 后影响其他区域；需要局部样式时生成有范围的规则，同时保留媒体查询和现有样式优先关系。

已有复杂内容必须保留，并显示可编辑范围。系统能够可靠操作的属性提供可视化编辑；缺少安全映射的操作明确拒绝并指出相关内容，提供高级 HTML 编辑入口。不得静默删除未知元素、脚本、属性、样式或未识别的内容。

保存后通过相同构建流程生成预览，核对编辑结果。HTML 编辑后重新解析并检查关联；解析或关联检查失败时保留用户输入，返回具体问题。

AI 生成与改写结果使用相同保存检查。改写展示内容差异，由用户选择采用的区域；保持页面标识、语言关联、收录设置和业务组件。采用结果后仍需用户单独发布。

## 10. 图片上传与资源管理

新增有权限检查的上传接口。使用成熟图片库检查实际格式、尺寸和解码结果；限制文件大小和总像素数量，返回明确错误。具体限制及支持格式由实施者依据部署容量确定，界面在上传前展示。拒绝不能安全处理的格式。

每次上传产生不可变的资源标识和路径，原文件名仅用于显示。替换图片创建新资源，不覆盖旧资源文件。上传完成前保留原图，显示进度；失败时保留原内容和失败原因。

上传资源先属于当前网站和工作草稿，提供有权限的预览读取。成功上传后替换当前选中元素；同时维护适用的响应式图片来源。保存通过页面版本检查建立资源引用；版本冲突不会覆盖他人内容。

资源记录包含归属、内容摘要、格式、尺寸、创建者和创建时间。已上传资源可在图片抽屉中再次选择，读取范围遵循当前网站及草稿权限。

发布制品只包含最终发布内容需要的本地资源。使用成熟 HTML 与 CSS 依赖识别图片、样式、字体及其关联资源；资源清单也允许系统组件明确声明依赖。无法确认本地依赖时终止预检并显示资源路径。

未选页面继续使用原资源。删除和替换不会立即删除仍被线上版本、其他草稿或保留的发布记录引用的文件。资源清理按引用和保留策略执行；具体保留周期作为部署配置记录。

## 11. Guide 与系统组件

抽屉中的 Guide 设置显示当前按钮文字、动作和目标。目标显示 screen 名称或页面标题，支持搜索及预览，内部继续使用稳定标识。

每个可编辑 Guide 按钮必须与具体的 `GuideOption` 建立明确映射；保存同时更新必要的 HTML 和 Guide 数据。修改后立即检查目标存在、入口有效、无循环、能够到达 CTA，以及既有系统规则。

检查问题能够定位到 screen、按钮和路径。用户可以保留尚未解决的问题继续编辑；普通保存记录编辑内容及检查结果，发布必须通过业务检查。实现时需要增加可表达未完成编辑的保存途径，公开构建和发布的校验继续严格执行。

询盘、地图、WhatsApp、语言切换和 Guide 使用专门组件编辑器管理参数。未知脚本在编辑模式中不得访问管理后台权限；体验模式执行时继续隔离。

## 12. 选择发布的数据与接口

扩展现有网站发布快照，建立页面版本、资源清单和发布任务记录。网站公开版本仍然对应完整发布制品。工作草稿的保存版本与发布版本分别维护。

发布预检输入包含网站、工作草稿、所选页面操作及预期页面版本。页面操作明确为发布更新、停止展示或删除。停止展示和删除只处理被选中的页面。

预检开始时比较所选页面的基础公开版本与最新线上内容。基础版本过期且双方内容存在变化时，要求完成内容合并并正常保存后重新预检，不允许直接用旧草稿覆盖线上修改。可以自动合并的独立修改采用现有合并能力；存在冲突时展示双方内容，由用户处理。若所选内容已经与线上相同，作为无需更新的项目提示。删除、停止展示及资源引用同样参与版本检查。

预检读取最新线上快照，覆盖所选页面，保留未选页面，应用确认的网站设置，形成完整候选快照。候选快照包含最终公开页面、语言关联、导航、SEO、资源和设置。

预检返回确认令牌、基础线上版本、所选内容摘要、操作清单、依赖问题和设置变化。确认令牌有有效期并绑定用户及权限范围；服务端检查确认时权限仍然有效。确认令牌不能代替权限检查。

用户确认后使用预检固定的内容发布。编辑器存在未保存内容时，先完成正常保存，再进行预检。预检之后的新编辑继续作为未发布更改。

相对于发布确认时的基础版本，所选页面的线上内容如果被他人更新，需要重新预检。未选页面的线上内容发生变化时，也重新构建候选并要求确认，防止使用旧快照覆盖新内容。服务端通过网站级发布锁和远端版本条件检查保证顺序。

发布接口必须显式提供页面操作列表和是否发布设置。页面操作与设置变化均为空时拒绝执行；只发布设置时允许页面列表为空，但必须存在经过预检和确认的设置变化。旧的整草稿发布接口需要迁移：旧界面更新后停止提供隐含全量发布路径；确实需要发布全部内容时，由用户明确选择全部页面并确认。

## 13. 设置、页面引用与公开输出

网站共用设置独立列出变化，默认不随页面发布。首次发布必须确认网站运行所需的完整设置；后续允许只发布设置，确认界面明确显示其全站影响。

发布检查在最终候选快照中执行：

- 地址与广告关键词路由冲突。
- 本地资源存在且用户有读取权限。
- 本站链接和 Guide 目标存在。
- 删除或停止展示的页面没有未处理的引用。
- 语言关联、Canonical、hreflang、sitemap 和收录设置有效。
- 网站设置能够支持全部最终公开页面。
- 询盘配置和广告 Guide 满足发布要求。

涉及未发布关联页面时展示具体标题、引用位置及操作入口，由用户补充选择并重新预检。无法静态确定的脚本行为明确列出检查范围，不宣称所有动态行为均已验证。

为保持导航、语言链接、地图、WhatsApp 及 sitemap 一致，可以根据完整候选快照重新生成公开 HTML。未选页面的正文、SEO、Guide 和页面资源版本保持线上记录；共用导航、语言链接及已确认的网站设置可以随本次发布更新。确认界面说明这些全站输出的影响。

旧地址变更后在同一次发布中移除原地址，并检查本站引用。自动重定向能力不属于已经确认的需求，实施者不得自行承诺存在该能力。

## 14. 发布执行、同步与恢复

发布从独立候选目录构建，不在用户正在编辑的工作草稿上进行公开内容合并或清理。发布候选的 Git 历史建立在最新公开版本上，仅包含所选页面、确认设置及必要资源。

现有远端接收机制需要检查候选基础版本，通过校验后原子切换完整公开版本。构建失败、版本冲突或上传失败时继续提供原有网站。发布任务使用幂等标识，重试不得重复创建网站、重复应用删除或生成重复发布记录。

远端成功后，本地记录发布版本和完整快照。远端成功而本地写入失败时，任务进入等待核对状态；通过任务标识及远端版本查询恢复记录。核对完成前阻止该网站的新发布，避免重复操作。公开切换与本地数据库不作为一个跨服务事务承诺。

工作草稿保持所有未发布内容。记录页面的基础公开版本，用于之后识别选中页面的发布冲突。其他草稿同步最新公开版本时，使用既有版本合并能力保留本地编辑，发生内容冲突时提供双方差异和选择入口。

发布记录保存操作人、时间、所选页面版本、完整公开版本、设置及资源摘要和检查结果。历史版本查看提供只读内容。涉及恢复内容时，使用正常文件编辑及保存流程形成新版本，不使用 Git 回滚操作。

## 15. 编辑与预览隔离

编辑画布在隔离 iframe 中运行，页面脚本不得读取管理后台令牌或直接调用管理接口。编辑控制与画布通过受校验的消息通信；检查窗口来源、会话标识、消息类型和内容结构，不接受页面脚本自行声明的授权。

编辑模式禁用用户页面脚本，由可信编辑桥接处理选择和属性变化；HTML 和 CSS 仍按原结构显示。体验模式使用独立隔离预览运行页面交互。编辑桥接和工具样式不得进入公开文件。

API 校验页面、资源、网站、草稿和用户的关联。上传、保存、预检、发布和恢复记录均独立检查权限。错误在发生位置返回明确结果；不得静默改用其他网站、资源或页面。

## 16. 迁移与兼容

迁移保持 `pageId`、`draftId`、已有 `siteId`、公开地址和远端标识。为已有线上快照补充页面内容摘要和资源记录；只有能够核对的快照才能作为选择发布基础。缺少可信快照时，先从远端公开版本核对，失败则阻止发布并说明原因。

未关联网站的草稿按第 4 节建立本地网站记录，保持权限与历史业务归属。已关联网站下的草稿继续归属原网站。现有报告和统计继续依据原有网站与页面标识读取。

编辑元数据采用版本号；首次打开时读取原内容生成映射，首次保存时才持久化。迁移不得自动重写全部 HTML、改变未选页面内容或发布尚未确认的内容。

数据库迁移和发布协议需提供版本兼容检查；遇到旧服务无法处理选择发布时显示升级要求，终止操作。

## 17. 验收条件

所有验收使用真实数据库、文件、API 和浏览器流程，不使用 mock 服务或固定成功结果。浏览器验证依据 DOM、内容、网络请求和公开输出，不主动使用截图或图像识别定位元素。

- 新建网站、首次发布、已有网站和多个草稿均能进入正确内容，权限及历史数据归属保持正确。网站入口能够读取有权限的历史草稿业务记录，来源明确且没有重复；草稿权限用户继续读取原有可访问记录。
- 列表筛选、分页、分类计数和状态准确；线上状态与编辑状态能够同时表达。
- 文字、图片、按钮和嵌套区域可选择，抽屉属性修改后预览、保存、重新打开和发布结果一致。
- 上传真实图片，检查格式、权限、上传失败、替换、响应式图片、重新选择和发布后访问；未选页面的原图继续有效。
- 区域添加、删除、复制、排序、键盘操作及撤销恢复有效；复制的表单和 Guide 标识不冲突。
- 已有通用页面、内容页和广告页通过 HTML、样式及业务行为回归。无修改打开保存不能产生内容丢失或错误的发布差异。
- 广告 Guide 可以通过抽屉修改，问题能够定位；循环、失效目标和无法到达 CTA 的内容无法发布。
- 选择单页和多页发布；其他未发布内容不进入公开 HTML、资源或远端发布历史。
- 停止展示、删除、地址修改和语言关联更新正确影响导航、sitemap 和公开地址。
- 共用设置只有明确确认后生效，更新后的公开输出与确认范围一致；只发布设置能够执行，无页面操作且无设置变化的请求被拒绝。
- 预检前线上页面已变化、确认后继续编辑、同时发布、其他成员更新、版本冲突、重复请求和权限撤销均正确处理。
- 构建失败、网络中断、远端成功后本地写入失败及服务重启可以根据真实任务状态恢复，原公开网站保持可访问。
- 编辑模式不执行访客操作，体验模式不产生线上统计和真实询盘发送；公开页面正常执行现有访客功能。
- 当前询盘、报告、生成、翻译、Google 集成、协作及备份恢复继续通过适用的回归检查。
- 执行项目要求的类型检查、构建和相关完整测试，记录实际结果。需要外部凭据的真实检查继续明确其执行状态。

## 18. 实施者负责的具体选择

在不改变已确认行为的前提下，实施者确定依赖及版本、具体接口名称、数据库字段和迁移编号、任务执行方式、属性白名单、设备尺寸、上传限制、资源保留周期及键盘快捷键。

需要形成可检查的选择依据，特别是编辑器对既有 HTML 与 CSS 的保存能力、Guide 映射方式、隔离画布通信、资源依赖检查和远端发布幂等行为。无法满足本文要求时应明确说明具体限制，不降低验收条件。
