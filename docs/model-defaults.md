# 模型与生成默认

> 页面生成、引导规划、文案、翻译、报告等业务模型默认使用 **DeepSeek V4**。  
> 必须可配置，不要固定到换不了。

## 默认

| 用途 | 默认 |
|------|------|
| 页面生成、引导规划、文案、翻译、报告等 | **DeepSeek V4** |

接入时的具体模型名以环境为准；与旧 LPS 一致时常见 id 为 `deepseek-v4-pro`（flash 等变体可另配）。

## 要求

1. 站点或部署环境能改默认模型，不必改代码。  
2. 复用 LPS `model-provider` 时，默认指向 DeepSeek V4 系列。
