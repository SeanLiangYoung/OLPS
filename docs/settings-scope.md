# 设置：放在哪里、不带什么

> 实现时以本文为准。

## 一、「设置」菜单

| 子菜单 | 内容 |
|--------|------|
| 常规 | 网站名称、网站地址、公司信息（名称、地址、电话、邮箱）、网站图标、社交账号链接、语言列表与默认语言 |
| 搜索引擎 | 允许搜索引擎收录、允许 AI 搜索引用、允许 AI 训练使用 |
| 内容类型 | 新建内容类型；修改名称、地址前缀、层级、字段 |
| 发布目标 | FTP / SFTP / S3 / OSS / COS 的连接、测试、启用与停用 |
| 成员 | 网站与草稿的所有者 |

## 二、放在其他模块的设置

| 设置 | 位置 |
|------|------|
| Logo、颜色、字体、页脚文字 | 「外观 → 自定义」，由当前主题的 `theme.json` 定义 |
| 导航菜单 | 「外观 → 菜单」 |
| 主题和插件固定文字的翻译 | 「外观 → 文字翻译」 |
| 询盘表单字段、通知邮箱 | 「插件 → 询盘表单 → 设置」 |
| WhatsApp 号码与按钮 | 「插件 → WhatsApp → 设置」 |
| Google 地图 API key | 「插件 → Google 地图 → 设置」 |
| Google Ads、GA4、Search Console、Meta Pixel 等平台连接，转化设置，Cookie 同意 | 「营销集成」 |
| 站内行为采集 | 「营销集成」，与第三方平台使用同一套标准事件和 Cookie 同意 |

## 三、不带的

| 项目 | 说明 |
|------|------|
| 巡检与优化策略 | 定期巡检不做；评价与优化使用「工具 → 报告」 |
| 企业知识库设置区块 | 每个网站已有独立知识库，资料在 AI 建站、AI 生成等流程里选择 |

## 四、知识库的用法

1. 没有「企业知识库」设置区块。
2. 每个网站只有一个独立知识库，在 AI 建站、AI 生成、报告等流程里选择需要使用的资料。
3. AI 生成时资料可选；选中后检索到的内容作为参考，生成内容以资料为准。
4. 资料需要用于另一个网站时复制到目标网站的知识库，复制后的资料分别维护。

## 五、保存位置

| 设置 | 保存位置 |
|------|----------|
| 常规、搜索引擎 | sandbox `source/site-settings.json` |
| 内容类型 | sandbox `source/collections/<collectionId>.json` |
| 外观、菜单 | sandbox `source/appearance.json` |
| 插件启用状态与普通设置 | sandbox `source/plugins.json` |
| 插件 `secret` 设置、营销集成凭据、发布目标凭据 | PostgreSQL，加密保存 |
| 成员 | PostgreSQL 所有权关联表 |

sandbox 里的设置随 Git 发布，参与 Pull 与 Push 合并；数据库里的设置按 [admin.md](admin.md) 第 6 节的范围规则归属草稿或网站。
