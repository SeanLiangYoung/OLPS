# 网站内容本地化

网站内容支持多种语言。后台界面使用中文。

## 1. 语言设置

- 内置简体中文（`zh-CN`）和英文（`en`）。新建网站默认启用这两种语言，默认语言为 `en`；领域默认值由 `defaultManagedSiteSettings` 与 `createDefaultSiteContent` 生成。
- 用户在「设置 → 常规」的语言选择器里添加任意语言，并选择默认语言。语言名称用 `Intl.DisplayNames` 显示。
- `SiteSettings.locales` 为语言对象列表，每项为 `{ code, dir }`；`dir` 为 `ltr` 或 `rtl`，阿拉伯语、希伯来语等语言自动设为 `rtl`。
- 校验规则由 API 执行：至少一种语言；默认语言必须在列表里；语言代码符合 BCP 47。
- 删除一种语言时，该语言的全部内容文件随之删除；删除前后台列出受影响的页面数量并要求确认。

## 2. 地址

每种语言都带前缀：

| 对象 | 地址 |
|------|------|
| 首页 | `/<locale>/` |
| 页面 | `/<locale>/<slug>/` |
| 内容类型 | `/<locale>/<prefix>/...`（见 [page-model.md](page-model.md)） |
| 404 页 | `/<locale>/404.html` |

根地址的 `index.html` 是跳转页，跳到默认语言的首页。跳转页包含 `<meta http-equiv="refresh" content="0; url=<默认语言>/">`、`location.replace` 和指向默认语言首页的 `canonical`，不进入 sitemap。

根目录的 `404.html` 使用默认语言的 404 页，页面上列出其他语言首页的链接。

非默认语言的 `slug` 在新建时与默认语言相同，可以修改。

## 3. 内容存放

- 页面、总列表页、分组、条目的语言相关内容，每种语言一个文件 `<locale>.json`，各语言的区块树互相独立。
- 内容类型字段的 `translatable` 决定字段是否按语言填写。
- 媒体的标题、替代文字、说明按语言填写。

## 4. 翻译状态

非默认语言的每个内容文件保存 `sourceHash`，即翻译时默认语言原文的哈希值。计算时排除 `locale`、`slug`、`sourceHash` 和 `updatedAt`，其余默认语言内容按 RFC 8785 规范化后计算 SHA-256。完整规则见 [design/domain-model.md](design/domain-model.md) 第 11 节。

| 状态 | 判断 |
|------|------|
| 未翻译 | 该语言文件不存在 |
| 已翻译 | `sourceHash` 等于默认语言原文当前的哈希值 |
| 原文已修改需要更新 | `sourceHash` 不等于默认语言原文当前的哈希值 |

页面列表、条目列表和编辑器显示每种语言的状态。

## 5. 翻译操作

- 编辑器顶部有语言切换。切换到非默认语言时，侧边显示默认语言的内容作为参照。
- 单页翻译：对当前页面执行 AI 翻译，保持区块结构，只翻译文字和可翻译字段。
- 整站翻译：对选定语言执行全部内容的 AI 翻译，可以只翻译「未翻译」和「原文已修改需要更新」的内容。
- 翻译完成后写入 `sourceHash`。翻译任务的规则见 [ai-generation.md](ai-generation.md)。

## 6. 主题和插件的固定文字

主题和插件里的固定文字（例如「阅读更多」、面包屑的「首页」、询盘表单的字段名和错误提示、Cookie 同意提示）由各自的 `languages/<locale>.json` 提供，内置主题和内置插件自带 `zh-CN` 与 `en`。

- 模板通过 `t` 过滤器读取：`{{ 'read_more' | t }}`。
- 查找顺序：`source/i18n/<locale>.json` 里用户修改过的文字 → 主题或插件自带的 `languages/<locale>.json`。
- 添加主题或插件没有提供的语言时，AI 生成这些文字的翻译，写入 `source/i18n/<locale>.json`。用户在「外观 → 文字翻译」里修改。
- 构建时发现缺少翻译的文字，直接报错终止，列出语言、来源（主题或插件）和文字键名。

## 7. 输出

- 每个页面的 `<html>` 带 `lang` 和 `dir`。
- 每个页面输出全部语言版本的 `hreflang`，`x-default` 指向默认语言的版本。只输出已发布的语言版本。
- `sitemap.xml` 里用 `xhtml:link` 写入各语言版本的对应关系。
- 根目录 `llms.txt` 按语言分节；`/<locale>/llms-full.txt` 为各语言的全文。
- 开启 `feed` 的内容类型输出 `/<locale>/<prefix>/feed.xml`。
- Pagefind 按 `lang` 分别建立索引，搜索只返回当前语言的结果。
- 日期和数字按页面语言用 `Intl` 格式化，在构建时写入 HTML。

## 8. 语言切换器

主题在页眉放置语言切换器，模板数据 `alternates` 提供同一页面在其他语言下的地址和语言名称。缺少某种语言版本时，该语言链接到它的首页。网站不按浏览器语言自动跳转。

## 9. 其他

- 必备页面每种语言各有一套。隐私政策、服务条款、Cookie 政策按语言分别生成。
- 询盘记录访客提交时所在页面的语言。
- 询盘表单的字段名、错误提示和提交成功页按页面语言显示。
