# 直接复用 vs 需要重做

> 对照旧 LPS 与当前 open-lps 需求。见 [tenant-context.md](tenant-context.md)、[packages.md](packages.md)。

**底下本事多半复用（含 SSO、租户、生成、技能、询盘）；上面的管站体验和一部分产品规则要重做。**  
运营走后台模块页 → HTTP API；命令行与外部系统 → 同一套 API / CLI。  
请求一律：**账号 token + 当前租户**。

---

## 一、直接复用

| 内容 | 怎么用 |
|------|--------|
| **SSO / 租户模型** | 复用；产品上强制「登录后先选租户、可切换」 |
| **specs（只读）、skills、CLI/能力表** | 在当前租户下调用；由模块页或自动化触发 |
| **model-provider** | 默认 DeepSeek V4 |
| **生成核心、评分报告、悬浮导览运行时、行为采集、询盘对接** | 复用 |
| **广告/分析适配、发布思路** | 复用并加强 SEO/sitemap 等 |

---

## 二、明确不带

| 内容 | 原因 |
|------|------|
| 对话配完整站 / 对话猜租户 / 对话工作台主壳 | 显式选租户 + 后台模块页管站 |
| 品牌与 Logo 设置、巡检策略 | 不需要 |
| Guide 文档流 | 只留悬浮 |
| 企业知识库设置块 | 流程里选库 |
| DeerFlow 等 | 历史债 |

---

## 三、需要重做 / 新做

| 内容 | 说明 |
|------|------|
| 登录后选租户 + 切换体验 | 可复用旧列表，交互做干净 |
| 当前租户下的 CMS 后台 | 模块页：三类页、发布态、Guide 可改、询盘、精简设置 |
| 广告页新规则 | 一词一址、共用一套屏、可改图、visited/后退、屏数可配 |
| 站点可配置项 | 多语言、地图、WhatsApp agent、屏数上限等 |
| Admin 挂在 SSO+当前租户上 | 不另造账号体系 |

---

## 四、总表

| 类别 | 复用 | 重做 | 不带 |
|------|------|------|------|
| 账号与租户 | SSO、租户、token+租户调服务 | 先选租户、切换体验 | 对话猜租户；另起账号 |
| 技能与生成 | specs/skills/生成/评分 | 词簇、共用屏、可改引导等产品规则 | 平行重写 |
| 界面 | 可抽组件 | CMS 模块化后台（租户内） | 对话壳；品牌/巡检/知识库开关/双导览 |

---

## 五、开工顺序

1. SSO → **选租户** → 进后台（可切换）  
2. 当前租户下：三类页 + 发布 + SEO/sitemap  
3. 挂复用生成/技能（token + 租户），由模块页触发  
4. 补一词一址、共用屏与可改 Guide、悬浮-only、流程选库、询盘、采集、可配置多语言/地图/WhatsApp、DeepSeek
