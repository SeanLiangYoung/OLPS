# CMS 独立升级命令计划

目标：通过 `npm run upgrade -w @olps/api` 完成数据库和旧网站升级。HTTP 服务只读取升级完成记录，未升级时终止启动。

升级命令检查加密配置，执行旧租户转换、CMS Schema、网站内容、索引、知识资料和历史询盘升级。全部成功后保存版本记录；重复执行保持现有内容提交。升级失败时保留未完成状态，服务拒绝启动。正式操作期间停止 API。
