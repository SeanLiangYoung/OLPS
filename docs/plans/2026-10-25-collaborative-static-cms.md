# 多人协作静态 HTML CMS 开发计划

目标：用户通过独立草稿协作编辑页面，预览内容并发布静态 HTML，能够管理页面的完整生命周期。

继续使用 Vue 管理后台、Hono API、PostgreSQL、Git 草稿及独立发布服务。同步使用现有 Pull/Push 与 Agent 冲突处理流程。保留工作目录中已有修改。
