# 租户怎么用

## 约定

1. **用现有 SSO 登录**（账号 → token）。  
2. **租户只使用 AI Sites 中的租户**（数字 ID + 名称）；open-lps 不另建租户表或成员表。  
3. **登录成功后，第一时间选择当前租户**（列表由 AI Sites `GET /api/v1/tenants` 按当前 token 返回；若只有一个可自动进入，仍应能看到自己在哪个租户）。  
4. **之后所有操作都在该租户下**：站点、页面、生成、发布、知识库选择、广告/分析连接、询盘、站点配置等。  
5. **允许切换租户**：切换后上下文整体换到新租户，不要把上一个租户的站点/页面混进当前操作。  
6. 请求各服务时：带上 **账号 token + 当前租户**（`X-Tenant-Id` 为 AI Sites 租户 ID）；服务端按该 token 在 AI Sites 的可见列表校验。

```text
SSO 登录
  → 从 AI Sites 拉取可见租户并选择（必做）
  → 在该租户下管站 / 生成 / 发布
  → 需要时切换租户，再继续
```

## 和后台管站的关系

- 多租户解决的是：**你属于哪些企业/组织、当前在为谁干活**（身份在 AI Sites）。  
- 后台 CMS 解决的是：**在当前租户里，把落地页站点管清楚**（三类页、发布态、Guide 可改、询盘、配置等）。  
- 租户选择是登录后的明确一步（或顶栏切换）。

「当前站点」指：**当前租户下、当前正在编辑的某一个站点**。
