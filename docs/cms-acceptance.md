# CMS 验收说明

## 页面与多人协作

打开管理后台，注册账号并创建工作草稿。分别创建通用页面、内容页面和广告承接页，编辑正文并保存。页面详情中的预览支持电脑、平板和手机宽度。广告页可以编辑屏幕、关键词和 Guide 选项，检查路径后预览。

在页面管理中选择需要公开的页面，点击“发布所选页面”，检查确认窗口列出的页面和网站设置，确认后使用返回的公开地址检查静态 HTML 和资源。暂停某个页面展示，选择该页面并发布后对应地址应返回 404；恢复展示并发布后应恢复访问。删除页面并发布后，公开地址和 sitemap 应同步更新。未选页面保留线上版本。

邀请第二个账号作为草稿及网站所有者。两个窗口同时打开同一页面，第二个窗口保存后，第一个窗口的旧版本保存应提示重新加载。分别创建关联同一网站的草稿，通过 Pull 和 Push 检查双方修改。需要人工选择的冲突在用户决定后继续执行。

## 生成、改写和翻译

生成页面选择知识库，添加真实文档；配置本地知识目录后，也可以导入 llm-wiki Markdown 文件。选择页面类型、语言，填写标题、地址和需求；广告承接页还需要提供关键词。提交后检查任务进度、错误和完成页面入口，刷新页面应能够继续查询任务。

配置 MiniMax 后，分别生成三类页面，检查正文、SEO、广告 Guide 和询盘表单，预览并发布。页面详情显示模型调用信息及知识来源；知识来源应与所选文档一致。页面改写应保留 pageId、语言关联、收录设置及业务记录。翻译应产生指定语言的页面并关联源页面；已有翻译的更新需要检查目标页面版本。

未配置模型凭据时提交任务，应显示明确失败信息，页面列表不会增加生成结果。改写失败应保留原页面。外部模型成功请求、真实输出质量和账户额度，需要在配置凭据后验证。

## 访客功能与 SEO

在设置中启用 WhatsApp，填写国际号码与入口文案；启用地图时填写 Google Maps key 和查询地址。发布后检查对应入口和地图。关闭开关并重新发布后，相关内容应同步更新。

启用行为采集并发布，通过真实浏览器打开页面、点击链接和 WhatsApp、提交询盘，在询盘及行为记录中检查结果。询盘表单需要使用有效姓名、邮箱和消息。

草稿预览不采集访客行为，网站的行为采集设置继续保留，发布页面依据该设置工作。

配置两种语言，在相关页面填写同一语言关联标识。发布后检查语言切换、Canonical、hreflang、Open Graph、Twitter、robots.txt、sitemap.xml 和 lastmod。标记为 noindex 的页面不应进入 sitemap，后台应显示缺少的翻译语言。

## 邮件、Google 与报告

未配置 SMTP 时，询盘应建立等待发送的任务。配置 SMTP 后提交真实询盘，在实际收件箱检查内容，并对照后台任务结果。错误凭据应产生可查询的失败；手工重发应产生可追踪任务。

配置 Google 客户端后完成真实账号授权，绑定有权限访问的 Ads 和 GA 资源，查询广告与分析数据；撤销授权后检查连接状态。保存资源标识不会代替 OAuth 授权。

报告页面可以运行页面检查。配置 MiniMax 后，使用草稿页面或公开 HTML 地址执行模型诊断，检查问题证据、来源地址、内容指纹和模型信息。通过诊断结果进入改写，确认知识库和需求后提交，完成预览、发布及再次诊断。

通过真实访客浏览、点击并提交询盘，在报告页面核对最近 28 天的统计。创建报告后增加访问记录，再次选择页面时当前统计应更新；历史报告保留创建时的数据。切换页面只显示对应页面的记录，统计中不包含联系人信息或询盘消息。撤销网站访问权限后，相关历史统计不能通过草稿报告列表读取。

## 自动检查与运行

执行 `npm run build`、`npm run typecheck`、`npm audit`、`npm run test` 和 `npm run test:e2e -w @olps/admin`。完整测试中的真实 Agent 流程需要本机登录或配置 `CURSOR_API_KEY`。浏览器测试不使用模拟服务，浏览器路径设置见 [本地 Docker 运行](local-docker.md)。

检查 `docker compose ps` 的四个服务状态。备份恢复需要同时保存数据库、API 数据和远端数据；按照运行文档恢复至独立数据库与 volume 后，检查账号登录、草稿、Git 历史和公开 HTML。

用户当前选择暂不配置外部凭据。MiniMax 成功生成、真实 SMTP 收件、Google 账号授权与查询、用户本地 llm-wiki 目录连接，以及 Docker Agent 认证后的冲突处理，均保留为配置后的真实服务验收项目。

当前真实 Agent 检查使用 macOS 已登录环境。Linux 容器已安装 CLI；容器认证及 Windows 原生运行验收需要对应配置与运行环境。
