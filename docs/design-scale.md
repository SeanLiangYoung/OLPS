# 设计尺度

需求里已经确定的内容，按完整设计写清楚，并实现到可以运行。

- 必备页面与树形内容类型、媒体库、区块式可视化编辑器、AI 建站与修改与翻译、主题与插件、营销集成、SEO 与 GEO、隐藏文件、纯静态产物与发布目标、多语言、询盘、本系统账号登录后选择工作草稿、accessToken、三端适配、管理 API 与独立远端服务分工，都属于当前设计，写全。
- 当前需求里没有的层次不加。独立 BFF、Redis、消息队列、一次性启动容器、服务之间再签发 token、为以后可能出现的规模预先增加的进程，都不加。AI Job、服务器端转化、投放数据取回、发布目标上传都在 API 进程内的后台任务中执行。
- 每个包、每个进程都要能说出它现在负责的事情。说不出当前职责的，不单独存在。
- 产品交互是后台模块页；对话工作台不加。
