# 设计尺度

需求里已经确定的内容，按完整设计写清楚，并实现到可以运行。

- 三类页面、一词一入口、一词一地址、共用一套屏、屏数上限默认可配置、唯一转化终点与询盘、引导关系可看可改、本系统账号登录后选择工作草稿、accessToken、搜索信息、站点地图、可配置多语言/地图/WhatsApp、三端适配、管理 API 与独立远端服务分工，都属于当前设计，写全。  
- 当前需求里没有的层次不加。独立 BFF、Redis、一次性启动容器、服务之间再签发 token、为以后可能出现的规模预先增加的进程，都不加。  
- 每个包、每个进程都要能说出它现在负责的事情。说不出当前职责的，不单独存在。  
- 产品交互是 Admin 模块页；对话工作台不加。
