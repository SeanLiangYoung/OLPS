## 独立升级验收

停止 API 后执行 `npm run upgrade -w @olps/api`；生产编译产物使用 `node services/api/dist/upgrade.js`。独立命令负责结构初始化、旧格式转换和业务资料升级。`server.ts` 只读取升级完成记录；生产启动依赖不含旧格式与升级模块。

真实子进程测试覆盖空库初始化、未升级启动拒绝、旧网站转换、失败后重试、并发升级拒绝、重复执行保持 Git 与数据库行版本，以及拒绝覆盖更高版本的数据库。编译后的升级入口和 HTTP 入口在真实 PostgreSQL、远端服务环境中也通过健康检查。

本次 `npm run build`、`npm run typecheck`、`npm test`、`npm run test:docs`、`npm run test:cms-docs`、`npm run check:docs` 和 `git diff --check` 全部返回 `0`。完整测试共 **136 份文件、450 项测试**；API 为 **49 份文件、91 项测试**。独立代码审查未发现可证实问题。

日志为本地 `.intermediate/upgrade-build.log`、`upgrade-typecheck.log`、`upgrade-all-tests.log`、`upgrade-doc-tests.log`、`upgrade-cms-doc-tests.log`、`upgrade-links.log` 和 `upgrade-compiled.log`。37 项验收记录中，**30 项已验证，7 项待外部验收**。
